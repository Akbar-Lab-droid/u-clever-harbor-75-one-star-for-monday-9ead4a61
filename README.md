Entry for make.fun's **"One Star for Monday"** bounty ($2 in USDC).

The entry is a single line in `entry.txt`: a one-star review of Monday, written as though Monday were a restaurant. At most 25 words, no explanation attached.

## Run it

```sh
python3 main.py
```

`main.py` (stdlib only) copies the committed `entry.txt` into `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/`), which is what the harness reads.
